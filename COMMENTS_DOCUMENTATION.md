# 📝 ДОКУМЕНТАЦИЯ ПО КОММЕНТАРИЯМ В MyForm.h

Все функции теперь имеют подробные XML комментарии в формате `/// <summary>`.

## 🆕 НОВЫЕ ВСПОМОГАТЕЛЬНЫЕ МЕТОДЫ

### 1. **`loadBitmaps()`**
```cpp
/// Загружает все изображения шашек и дамок из файлов
```
- **Назначение:** Единая точка загрузки всех бэрмапов
- **Избегает дублирования:** Раньше этот код повторялся в 3 местах
- **Загружает:**
  - `blackCasualBmp` - чёрная шашка
  - `whiteCasualBmp` - белая шашка
  - `blackQueenBmp` - чёрная дамка
  - `whiteQueenBmp` - белая дамка

### 2. **`createVisualBoard()`**
```cpp
/// Создает визуальную доску 8x8 с PictureBox элементами
```
- **Параметры:** Нет
- **Возвращает:** Ничего (модифицирует `pb` массив)
- **Процесс:**
  1. Инициализирует массив из 64 PictureBox'ов
  2. Для каждой клетки устанавливает позицию, размер, цвет
  3. Добавляет обработчик клика
  4. Добавляет на форму (в Controls)
- **Побочный эффект:** Модифицирует глобальные переменные

### 3. **`clearPictureBoxes()`**
```cpp
/// Удаляет все PictureBox элементы доски и освобождает память
```
- **Назначение:** Очистка перед созданием новой доски
- **Важно:** Вызывает `delete` для избежания утечек памяти
- **Используется в:**
  - `returnToMainMenu()` - при выходе в меню
  - `setupLoadedGameBoard()` - при загрузке игры

### 4. **`getCellColor(int row, int col)`**
```cpp
/// Возвращает цвет клетки доски для координат (row, col)
```
- **Параметры:**
  - `row` - строка (0-7)
  - `col` - столбец (0-7)
- **Возвращает:**
  - `LightGray` если (row + col) четное
  - `DarkGray` если (row + col) нечетное
- **Выгода:** Единое место для логики цветопередачи (вместо 7+ дублирований)

### 5. **`deselectPiece()`**
```cpp
/// Отменяет выбор фигуры и восстанавливает исходное состояние доски
```
- **Процесс:**
  1. Убирает зелёное выделение (clearValidMoves)
  2. Восстанавливает исходный цвет выбранной клетки
  3. Сбрасывает флаг выбора
- **Используется когда:**
  - Игрок кликает на ту же фигуру (отмена выбора)
  - Игрок делает невалидный ход

### 6. **`executeAIMove(color aiColor)` ⭐ ГЛАВНЫЙ МЕТОД**
```cpp
/// Выполняет ход ИИ с поддержкой обязательных рубок (цепочка рубок)
```
- **Параметры:**
  - `aiColor` - цвет фигур ИИ (black или white)
- **Раньше дублировался 3 раза:**
  1. `startNewGame()` - первый ход ИИ (27 строк)
  2. `pictureBox_Click()` - ответ ИИ (27 строк)
  3. `setupLoadedGameBoard()` - после загрузки (27 строк)
- **Теперь:** Один вызов - `executeAIMove(black)`
- **Алгоритм:**
  1. Отключает форму (Enabled = false)
  2. Вызывает `Application::DoEvents()` для обновления интерфейса
  3. Ждет 500ms для визуального feedback'а
  4. Получает лучший ход через `getBestMove()`
  5. Выполняет ход через `makeMove()`
  6. Обновляет доску и статус
  7. **ЦИКЛ:** Если есть обязательная рубка:
     - Ждет 300ms
     - Получает продолжающий ход
     - Выполняет ход
     - Обновляет доску
  8. Включает форму (Enabled = true)

### 7. **`showGameBoard()`**
```cpp
/// Подготавливает интерфейс для отображения игровой доски
```
- **Скрывает:**
  - easyButton, normalButton, hardButton
  - colorLabel, blackColorButton, whiteColorButton
  - loadInitialButton
- **Показывает:**
  - saveButton (сохранить игру)
  - menuButton (выход в меню)
- **Используется в:**
  - `startNewGame()` - при начале новой игры
  - `setupLoadedGameBoard()` - при загрузке

## 🎮 ОСНОВНЫЕ МЕТОДЫ ИГРЫ (С НОВЫМИ КОММЕНТАРИЯМИ)

### **`startNewGame()`**
```cpp
/// Инициализирует новую игру
```
- **Процесс:**
  1. Удаляет старую доску
  2. Создает новую доску
  3. Загружает изображения
  4. Создает визуальную доску
  5. Если человек играет белыми - ИИ ходит первым
- **Вызывается:** При выборе цвета фигур

### **`updateBoard()`**
```cpp
/// Обновляет визуальную доску согласно текущему состоянию gameBoard
```
- **Процесс:**
  1. Проходит по всем 64 клеткам
  2. Для каждой клетки:
     - Получает фигуру из gameBoard
     - Выбирает нужный бэрмап (черная/белая, шашка/дамка)
     - Копирует бэрмап в PictureBox
- **Важно:** Создает КОПИЮ бэрмапа (gcnew Bitmap(img))

### **`updateStatus()`**
```cpp
/// Обновляет строку статуса с информацией о игре
```
- **Отображаемая информация:**
  - Количество черных и белых фигур
  - Уровень сложности ИИ
  - Чей ход (ЧЕРНЫЕ или БЕЛЫЕ)
  - Если игра окончена: кто выиграл
- **Вызывается:** После каждого хода

### **`showValidMoves(int fromX, int fromY)`**
```cpp
/// Показывает допустимые ходы для фигуры на позиции (fromX, fromY)
```
- **Процесс:**
  1. Проходит по всем 64 клеткам
  2. Проверяет валидность каждого хода
  3. Если ход валиден:
     - Сохраняет исходный цвет
     - Меняет цвет на LimeGreen (ярко-зеленый)
- **Параметры:** Координаты выбранной фигуры
- **Используется:** При выборе фигуры

### **`clearValidMoves()`**
```cpp
/// Восстанавливает оригинальные цвета показанных допустимых ходов
```
- **Важно:** Не восстанавливает цвет выбранной клетки (она остается cyan)
- **Используется:** При деселекции или невалидном ходе

### **`pictureBox_Click()` ⭐ ГЛАВНЫЙ ОБРАБОТЧИК**
```cpp
/// Обработчик клика по клетке доски
```
- **Логика:**
  1. Если игра окончена - выход
  2. Если это ход ИИ - выход
  3. Если фигура не выбрана:
     - Проверяет обязательную рубку
     - Выбирает фигуру и показывает ходы
  4. Если фигура выбрана:
     - a) Если кликнул на ту же фигуру - отменяет выбор
     - b) Если кликнул на другую клетку:
       - Проверяет валидность хода
       - Если валиден - выполняет ход и ход ИИ
       - Если невалиден - пытается выбрать новую фигуру
